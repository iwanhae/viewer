Embedding model–

Resets every ready and failed embedding to pending. The background workers then re-embed the whole library from the stored originals — this is the recovery path for a lost vector store, and it takes a long time.

Recovery actions

Returns processing embeddings to pending so a worker can claim them again. With the box checked, only expired leases are released; unchecked, every processing row is force-released — in-flight workers' results will be rejected and those blobs get re-embedded.
